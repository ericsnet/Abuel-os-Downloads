## Requisitos

- Ordenador Intel/AMD de 64 bits compatible con una versión moderna de Chrome.
- 2 GB de RAM como mínimo; 4 GB recomendados.
- USB de 4 GB o más para crear el medio de arranque.

## Crear un USB de arranque

1. Descarga la ISO desde la sección **Releases**.
2. En Windows, utiliza [Rufus](https://rufus.ie/) en modo **DD** o [Ventoy](https://www.ventoy.net/).
3. En Linux, puedes usar una herramienta de grabación de imágenes como GNOME Disks.
4. Verifica la suma SHA-256 de la ISO antes de usarla.

**Aviso:** grabar una imagen en una unidad puede borrar todos sus datos. Comprueba cuidadosamente qué unidad has seleccionado.
