# abuel-os — Descargas

**Página oficial de descargas de abuel-os**, una distribución basada en Debian para personas mayores, con un escritorio sencillo y administración separada para la persona responsable.

> Este repositorio público está separado del [repositorio privado de desarrollo](https://github.com/ericsnet/Abuel-os). Aquí solo se publicarán documentación de descarga, sumas de verificación y archivos ISO en **GitHub Releases**; no se incluirá el código fuente ni los archivos de construcción.

## Requisitos

- Ordenador Intel/AMD de 64 bits compatible con una versión moderna de Chrome.
- 2 GB de RAM como mínimo; 4 GB recomendados.
- USB de 4 GB o más para crear el medio de arranque.

## Crear un USB de arranque

1. Descarga la ISO desde **Releases** cuando esté publicada.
2. En Windows, utiliza [Rufus](https://rufus.ie/) en modo **DD** o [Ventoy](https://www.ventoy.net/).
3. En Linux, usa una herramienta de grabación de imágenes como GNOME Disks.
4. Verifica la suma SHA-256 de la ISO antes de usarla.

**Aviso:** grabar una imagen en una unidad puede borrar todos sus datos. Comprueba cuidadosamente qué unidad has seleccionado.

## Primer inicio de la versión 1.0.2
