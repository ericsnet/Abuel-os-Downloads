# abuel-os 1.1.0

Versión centrada en dos cosas: que el sistema sea mediblemente más rápido y que
el escritorio deje de parecer viejo, con identidad propia.

## Contenido de esta carpeta

| Fichero | Qué es |
|---|---|
| `CHANGELOG.md` | Todo lo que incluye esta versión |
| `KNOWN_ISSUES.md` | Fallos y limitaciones reales de esta versión |
| `RELEASE.md` | Artefacto, tamaño, SHA256 y enlace de descarga |

## Resumen

- Pantalla de inicio `abuelo-inicio` con saludo, reloj y tarjetas grandes.
- Tema automático día/noche, con temas claro y oscuro de marca.
- Login, panel y fondos con la misma identidad (crema, navy y ámbar).
- Recorte de servicios y paquetes, zram con lz4 y arranque silencioso.
- **ISO construida** el 2026-11-22 (1,77 GB), pendiente de arranque y publicación.
- Plan completo y criterios de aceptación en
  [`docs/PLAN_1.1.0.md`](../../docs/PLAN_1.1.0.md).
