# Índice de versiones

Cada versión publicada tiene su propia carpeta con lo que incluyó, sus fallos
conocidos y los datos del artefacto. La carpeta se crea con
`python tools/new-version.py <versión>`.

En este repositorio cada versión publicada tiene además su carpeta de descarga en la
raíz: `1.0.0/`, `1.0.1/`, `1.0.2/`, `1.0.3/` y `1.0.4/`, con `abuelo-os-amd64.iso`,
`abuelo-os-amd64.iso.sha256` y `RELEASE.md`.
