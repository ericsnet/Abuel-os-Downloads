# abuel-os 1.0.9

Versión sin autologin, con arranque más ligero, instalador personalizado y
correo Outlook web.

## Contenido

| Fichero | Qué es |
|---|---|
| `CHANGELOG.md` | Cambios de esta versión |
| `KNOWN_ISSUES.md` | Fallos y limitaciones reales |
| `RELEASE.md` | Artefacto y verificación |
| `UPDATES.md` | Flujo desde 1.0.8 |

## Resumen

- LightDM muestra las cuentas `abuelo` y `responsable`; no hay autologin.
- La cuenta mayor conserva `abuelo-update --check`, pero no instala nada.
- El responsable tiene panel, actualizaciones y terminal root.
- El instalador tiene marca y presentación propias.
- El correo abre `https://outlook.live.com/mail/`.
